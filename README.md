# ربات تلگرام هوش‌مصنوعی (Groq) + پنل ادمین روی Vercel

یه ربات تلگرام حرفه‌ای با دکمه (بدون نیاز به دستور تایپی) که با Groq کار می‌کنه، به‌علاوه
یه پنل مدیریت وب برای دیدن لیست اعضا و ارسال پیام به‌شون.

## امکانات

- **منوی دکمه‌ای دائمی** زیر کادر تایپ (به‌جای `/command`):
  - 🖼 ساخت تصویر
  - 🧹 پاک کردن حافظه
  - ℹ️ راهنما
  - 🛠 پنل ادمین (فقط برای ادمین‌ها نمایش داده می‌شه)
- چت آزاد با هوش مصنوعی (کدنویسی، طراحی پروژه، هر سوالی)
- تولید تصویر رایگان (Pollinations.ai، بدون نیاز به کلید)
- حافظه‌ی کوتاه‌مدت گفتگو
- **ساخت پروژه‌ی چندفایلی**: بگو «یه ربات تلگرام با موضوع X برام بساز»، مدل فایل‌ها
  رو با ساختار درست تولید می‌کنه (مثلاً `package.json`، `index.js`، `README.md`)،
  بات خودکار همه رو **zip** می‌کنه و به همراه توضیحات برات می‌فرسته
- **تشخیص زبان برنامه‌نویسی**: هر بلاک کد که مدل تولید می‌کنه بر اساس زبانش
  (پایتون، جاوااسکریپت، و غیره) با پسوند درست ذخیره و فرستاده می‌شه
- **ارسال کد به‌صورت فایل**: کدهای بلند خودکار هم توی چت نشون داده می‌شن هم
  به‌صورت فایل قابل دانلود فرستاده می‌شن؛ برای کدهای کوتاه‌تر هم کافیه بعد از
  جواب بنویسی «به‌صورت فایل بفرست» یا «دانلودش کن» تا همون کد قبلی رو به‌صورت
  فایل/zip دوباره برات بفرسته
- **بررسی فایل آپلودی**: کافیه یه فایل zip (یا یه فایل کد/متنی تکی مثل .py، .js،
  .json) رو مستقیم توی تلگرام برای بات بفرستی — خودش دانلود و بازش می‌کنه،
  ساختارش رو می‌خونه و بررسی/تحلیلش می‌کنه. می‌تونی با caption روی فایل هم بگی
  دقیقاً چی می‌خوای (مثلاً «باگ‌هاشو پیدا کن»)، وگرنه خودش یه بررسی کلی می‌ده.
- **پنل ادمین وب**: لیست کامل اعضا (نام، یوزرنیم، شناسه، آخرین فعالیت) +
  ارسال پیام همگانی یا به یک نفر خاص

## مرحله ۱: ساخت بات تلگرام

1. به [@BotFather](https://t.me/BotFather) پیام بده → `/newbot` → توکن رو نگه دار.

## مرحله ۲: کلید Groq

1. https://console.groq.com → ثبت‌نام رایگان → **API Keys** → **Create API Key**.

## مرحله ۳: دیپلوی روی Vercel

```bash
npm install -g vercel
cd telegram-groq-bot
vercel
```
یا از طریق گیت‌هاب: پوش کن و توی vercel.com → **Add New Project** → دیپلوی کن.

## مرحله ۴: ساخت دیتابیس KV (لازم برای پنل ادمین و حافظه)

1. توی Vercel Dashboard پروژه رو باز کن → تب **Storage** → **Create Database** → **KV**.
2. بعد از ساخت، **Connect Project** بزن و همین پروژه رو انتخاب کن.
3. Vercel خودش `KV_REST_API_URL` و `KV_REST_API_TOKEN` رو اضافه می‌کنه.

> بدون این مرحله، چت آزاد کار می‌کنه ولی حافظه‌ی گفتگو، لیست اعضا، و پنل ادمین غیرفعال می‌مونن.

## مرحله ۵: متغیرهای محیطی

توی **Project Settings → Environment Variables** این‌ها رو اضافه کن (فایل `.env.example` رو ببین):

| متغیر | توضیح |
|---|---|
| `TELEGRAM_BOT_TOKEN` | توکن از BotFather |
| `GROQ_API_KEY` | کلید از console.groq.com |
| `TELEGRAM_WEBHOOK_SECRET` | یه رشته‌ی رندوم دلخواه (`openssl rand -hex 24`) |
| `ADMIN_CHAT_IDS` | شناسه‌ی عددی چت خودت در تلگرام (پایین توضیح داده شده) |
| `ADMIN_PANEL_TOKEN` | یه رشته‌ی رندوم دیگه، برای محافظت از پنل ادمین |

بعد از اضافه کردن env، از تب **Deployments** یه **Redeploy** بزن.

### چطور شناسه‌ی چت خودم رو پیدا کنم؟

ساده‌ترین راه: به [@userinfobot](https://t.me/userinfobot) توی تلگرام پیام بده،
یه عدد بهت می‌ده (مثل `123456789`) — همون رو توی `ADMIN_CHAT_IDS` بذار.
اگه چند نفر ادمین هستن، با کاما جداشون کن: `111,222,333`

## مرحله ۶: وصل کردن وبهوک تلگرام

```bash
curl -X POST "https://api.telegram.org/bot<TELEGRAM_BOT_TOKEN>/setWebhook" \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://your-project.vercel.app/api/webhook",
    "secret_token": "<همون TELEGRAM_WEBHOOK_SECRET>"
  }'
```
جواب موفق: `{"ok":true,"result":true,...}`

## مرحله ۷: تست

توی تلگرام به بات پیام بده و `/start` رو بزن. دکمه‌های زیر صفحه ظاهر می‌شن.
اگه چت آیدی‌ت توی `ADMIN_CHAT_IDS` باشه، دکمه‌ی «🛠 پنل ادمین» هم نشون داده می‌شه —
روش بزن تا لینک پنل وب برات بیاد.

آدرس مستقیم پنل: `https://your-project.vercel.app/api/admin?token=<ADMIN_PANEL_TOKEN>`
**این لینک رو با کسی به اشتراک نذار** — هرکی این لینک رو داشته باشه می‌تونه لیست اعضا رو
ببینه و به همه پیام بده.

## ساختار پروژه

```
telegram-groq-bot/
├── api/
│   ├── webhook.js          ← هندلر اصلی بات (دکمه‌ها، چت، تصویر)
│   ├── index.js            ← health check
│   ├── admin.js            ← صفحه‌ی وب پنل ادمین (HTML)
│   └── admin/
│       ├── users.js        ← API: لیست اعضا (JSON)
│       └── broadcast.js    ← API: ارسال پیام همگانی/تکی
├── lib/
│   ├── groq.js             ← ارتباط با Groq API
│   ├── telegram.js         ← ارسال پیام/عکس/کیبورد به تلگرام
│   ├── image.js            ← تولید تصویر (Pollinations.ai)
│   ├── memory.js           ← حافظه‌ی گفتگو (KV)
│   ├── users.js            ← دایرکتوری اعضا + وضعیت موقت (KV)
│   ├── kv.js               ← کلاینت مشترک Vercel KV / Upstash REST
│   ├── adminAuth.js        ← احراز هویت ساده‌ی پنل ادمین
│   ├── codeExtract.js      ← تشخیص پروژه‌ی چندفایلی / بلاک‌های کد و زبانشون
│   ├── zip.js              ← ساخت فایل zip (با jszip)
│   ├── codeDelivery.js     ← تصمیم‌گیری و ارسال کد به‌صورت فایل/zip
│   └── fileReview.js       ← خوندن و خلاصه‌سازی فایل zip/کد آپلودی
├── vercel.json
├── package.json
└── .env.example
```

## نکات

- **امنیت پنل ادمین**: احراز هویت فقط با یک توکن مخفی توی URL انجام می‌شه —
  برای استفاده‌ی شخصی کافیه، ولی یه سیستم لاگین کامل نیست. توکن رو طولانی و
  رندوم انتخاب کن و لینک رو جایی که در دسترس عموم باشه (مثل گیت‌هاب پابلیک) نذار.
- **نرخ ارسال پیام همگانی**: بین هر پیام حدود ۴۰ میلی‌ثانیه فاصله گذاشته شده تا
  از محدودیت نرخ تلگرام (~۳۰ پیام در ثانیه) عبور نکنیم. برای چند صد کاربر مشکلی
  پیش نمیاد؛ برای دیتابیس‌های خیلی بزرگ (چند هزار نفر) بهتره صف/queue جدا اضافه بشه.
- **تولید تصویر**: از Pollinations.ai (رایگان) استفاده شده. برای کیفیت بالاتر
  می‌تونی `lib/image.js` رو با یه سرویس پولی (مثل gpt-image-1) عوض کنی.
- **مدل پیش‌فرض Groq**: `openai/gpt-oss-120b` (جایگزین رسمی Llama 3.3 که در
  ۲۰۲۶ منسوخ شد). با env variable `GROQ_MODEL` قابل تغییره.
- بدون تنظیم `ADMIN_PANEL_TOKEN`، پنل ادمین به‌طور کامل غیرفعال و قفل می‌مونه
  (fail-closed) — یعنی حتی بدون توکن هم هیچ‌کس نمی‌تونه واردش بشه.
- **وابستگی جدید**: پروژه از پکیج `jszip` برای ساخت فایل‌های zip استفاده می‌کنه.
  نیازی به کار دستی نیست — Vercel موقع دیپلوی خودش `npm install` رو اجرا می‌کنه.
  برای اجرای محلی هم کافیه قبل از `vercel dev` یه بار `npm install` بزنی.
- محدودیت دانلود فایل برای بات‌های تلگرام ۲۰ مگابایته؛ فایل‌های بزرگ‌تر
  (چه zip باشن چه فایل تکی) قابل بررسی نیستن و بات همین رو بهت اطلاع می‌ده.
